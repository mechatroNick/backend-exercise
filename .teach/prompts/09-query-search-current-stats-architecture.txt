## Source anchors and bounded claims

- Search uses owner-scoped repository predicates, filters, eager tag loading, stable pagination, and total.
- `BookmarkStatsReader` is a narrow named-parameter raw-SQL reader for current user statistics.
- A fresh snapshot may later accelerate stats, but canonical live raw SQL preserves body semantics.

## Abstracted teaching intent

Show two protected views over one canonical data source. List/search uses shared filters and bounded page pagination. Stats intentionally crosses a narrow raw-SQL island for totals, top tags, and months. Both paths remain owner-scoped and all-current.

## Distilled Image Prompt

Flat 2D vector technical schematic on a clean white background displaying two owner-scoped Bookmarks API read paths: search and canonical current statistics. Monochromatic professional color scheme with subtle muted color accents, engineering-grade precision. No 3D effects, no gradients, no photorealism. Deep-purple routes, brick-red user-scope badges, muted-orange filters, royal-blue repository and SQLite, teal aggregate reader, slate response envelopes.

Keep the two read models intentionally different but source-consistent. The upper lane is a search/list contract: an authenticated user id and normalized filters bind to owner-scoped repository reads, stable ordering, a page response, and a total computed under the same scope. Put every filter chip inside one orange funnel before the repository, never on the response side. The lower lane is the canonical current-statistics contract: it has its own route and parameterized raw-SQL reader, but it uses the same user scope and the same live bookmarks/tags source. Draw the teal aggregate island as a narrow, controlled escape hatch from ORM-shaped queries, not as a second analytics database.

Place the operational boundary near the statistics result. A request can read a valid snapshot when current, while a dirty or unavailable snapshot state falls back to canonical live raw SQL; the returned public semantics remain current and user-scoped. Use a modest slate fallback arrow, not a flashy failover architecture. The diagram must not turn Track 07’s private weekly projections into a public history endpoint. Show N+1 and string-interpolated raw SQL as crossed-out red cards at the edge, while named parameters, one aggregate reader, and bounded query-count proof stay in the accepted teal/green path.
