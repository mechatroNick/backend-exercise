## Source anchors and bounded claims

- `0001_core_schema` establishes users, bookmarks, tags, and the composite association.
- `app.db.engine` enables `PRAGMA foreign_keys = ON` on every connection.
- Database DDL enforces relational/length/uniqueness/index guarantees; DTOs/services own
  higher-level input normalization later.

## Technical style instruction

Use royal blue (#1D4ED8) for table cards and SQLite, forest green (#15803D) for
constraint badges, muted orange (#EA580C) Alembic engine, slate (#475569) revisions,
brick red (#B91C1C) rejected invalid rows. White background, clean crow-foot-like links,
short labels, no SQL text or rendered hex values.

## Abstracted teaching intent

Teach that durable privacy and data correctness begin in migrations and database
constraints: users own bookmarks; bookmarks and globally canonical tags join through a
composite-key table; every connection has foreign keys enabled; migrations are the sole
schema constructor. Later HTTP policy does not replace these lower guarantees.
