## Source anchors and bounded claims

- Date bounds are half-open UTC days; LIKE literals are escaped.
- Items and total share predicates and deterministic `created_at DESC, id DESC` ordering.
- Stats aggregates bind parameters and return public `count` fields.

## Technical style instruction

White two-panel correctness microscope. Pale-blue calendar/query panel, teal aggregate panel, muted-orange transformations, royal-blue database, brick-red anti-patterns, forest-green fixture scale. No SQL/code/hex text or generated image tables.

## Abstracted teaching intent

Teach boundaries: inclusive calendar date means before next UTC midnight; literal wildcard input must not become a wildcard; stable id tie-break makes pagination deterministic; count and page use same scope; aggregate SQL uses named parameters rather than interpolation.

## ASCII layout plan

```text
 Date → UTC start / next midnight → AND predicates → order → page + total
 SQLite → totals | top tags | months → count
 bad edges: end guess | interpolate | unbounded
```

## Distilled Image Prompt

Pale-blue calendars, muted-orange transformations, royal-blue query/data, teal aggregates, forest-green fixture scale, brick-red rejected alternatives.

Teach the boundary semantics as explicit transformations, not vague date filtering. A client-supplied UTC date enters a pale-blue calendar, becomes inclusive start-of-day and exclusive next-midnight bounds, and both bounds join the owner/filter predicate through an AND diamond. The lower edge should show that a date is not converted by guessing an inclusive end or by relying on local machine time. Keep title matching separate: a tiny protected glyph trio for percent, underscore, and escape sits beside the title filter, then feeds the same scoped predicate. No literal SQL values should be rendered.

Make stable pagination visible as a paired read contract. After filtering, a blue ordering card holds timestamp then immutable id tie-breaker; two parallel arrows lead to page rows and total count, both carrying the same-scope chip. This avoids an ambiguous page/total mismatch. In the aggregate panel, connect the live SQLite source to totals, top tags, and monthly series through named-parameter teal arrows, then merge to a response that visibly labels `count`. Place a green fixture-scale balance below the aggregates to indicate query-count and N+1 tests without inventing an analytics pipeline. Red anti-pattern cards should be visibly rejected: unbounded scan, client-side aggregation, local-time ambiguity, interpolated SQL, and guessed inclusive end.
